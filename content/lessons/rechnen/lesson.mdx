Hier gibt es nur ein Zeichen, `/`, und die **Typen der Zahlen** entscheiden: Zwei ganze Zahlen ergeben eine ganze Zahl. Sobald eine Seite eine Kommazahl ist, wird mit Komma gerechnet. Das ist eine der häufigsten Fehlerquellen überhaupt: `1 / 2` ist `0`.

</Nur>

## Werte einlesen

Ein Programm, das immer dasselbe ausrechnet, ist langweilig. Über die **Eingabe** bekommt es Werte von außen. Das Beispiel liest einen Namen und ein Alter:

<Code name="eingabe" />

Eine Eingabe ist zunächst immer Text. Wer damit rechnen will, muss den Text in eine Zahl umwandeln.

<Nur lang="python">

`input()` liefert eine Zeile als Text. `int(...)` macht daraus eine ganze Zahl, `float(...)` eine Kommazahl. Ohne Umwandlung wäre `"16" + 1` ein Fehler.

</Nur>

<Nur lang="java">

Ein `Scanner` zerlegt die Eingabe. `nextLine()` liest eine ganze Zeile als Text, `nextInt()` die nächste ganze Zahl. Die Zeile `import java.util.Scanner;` ganz oben macht den Scanner verfügbar.

</Nur>

<Nur lang="c">

`scanf` liest nach einem Muster: `%d` erwartet eine ganze Zahl, `%s` ein Wort. Das `&` vor `alter` übergibt die **Adresse** der Variable, damit `scanf` den Wert dort ablegen kann – was das genau bedeutet, klärt die Lektion über Zeiger. Die `49` in `%49s` verhindert, dass ein zu langer Name über das Ende des Arrays hinausschreibt.

</Nur>

<Nur lang="cpp">

`std::cin` ist das Gegenstück zu `std::cout`: Mit `>>` holst du Werte aus der Eingabe heraus. Die Umwandlung passiert automatisch passend zum Typ der Variable.

</Nur>

<Nur lang="rust">

Einlesen ist in Rust ausführlich, weil jeder Schritt sichtbar ist: `read_line` hängt eine Zeile an einen `String` an, `trim()` entfernt den Zeilenumbruch, `parse()` wandelt in eine Zahl um. Die `unwrap()`-Aufrufe bedeuten: „Wenn hier etwas schiefgeht, brich ab." Besser geht das mit der Lektion zur Fehlerbehandlung.

</Nur>

In den Aufgaben ist das Einlesen meistens schon vorgegeben, damit du dich auf das eigentliche Thema konzentrieren kannst.
